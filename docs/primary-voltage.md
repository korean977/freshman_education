# R2·R3 84 검출점: 89 단로기 1차측

R2·R3의 84는 각각 **89-R2·89-R3 1차측(단로기 앞 연계선 측)** 전압을 감지한다. 사용자가 확인한 현장 조건에 따라 **온수 측은 좌측 변전소에서 상시 공급**받으므로 89-R2 1차측과 R2의 84는 항상 가압·동작 상태다. 온수 측 전원은 초기화·단로기 개방·차단기 개방·보호 트립으로 해제되지 않는다.

## 검출점과 전원

```text
좌측 변전소 → 온수 측 [R2 84 검출점 · 상시 가압] ─ 89-R2 ─ 52-R2 ─ 공통 AC 모선
상동 측 외부 전원 → [R3 84 검출점] ─ 89-R3 ─ 52-R3 ─ 공통 AC 모선
```

| 조건 | R2 84 | R3 84 |
| --- | --- | --- |
| 초기 전체 기기 개방 | 동작(온수 상시 공급) | 비동작(상동 외부 전원 초기 무가압) |
| 해당 89·52 모두 개방, 외부 연계선 가압 | 동작 | 동작 |
| 해당 89 개방, 외부 연계선 가압 | 계속 동작 | 계속 동작 |
| 해당 89 개방, 해당 외부 전원 없음, 공통 모선만 가압 | 온수 공급으로 동작 | 비동작. 모선 전압이 열린 89를 넘어 전달되지 않음 |
| 해당 외부 전원 없음, 해당 89와 RUN 52를 통해 모선으로부터 역가압 | 온수 공급으로 동작 | 동작 |
| 해당 52가 TEST 투입 | 온수 공급으로 동작 | TEST 차단기는 주회로 연결로 계산하지 않음. 상동 외부 전원이 있으면 동작 |

`power-network.js`의 검출 노드는 R2=`onsu`, R3=`sangdong`이다. 89와 52 사이 구간인 `r2a`·`r3a`는 84 검출점과 구분한다. 따라서 RUN 52 투입으로 이 중간 구간이 가압되더라도 89가 개방돼 있으면 상동 측 84가 그 전압을 감지하지 않는다.

전압 감지와 도면 선로 색은 한 연결 모델을 공통 사용한다. 한전 수전과 온수 측 공급은 가압으로 고정한다. 상동 측 외부 전원만 가압 여부를 설정할 수 있고 초기값은 무가압이다. 외부 전원 설정이 꺼져 있어도 RUN 52와 89를 통한 역가압이 있으면 상동 측 실제 검출 전압과 84는 동작한다.

R2_84X·R3_84X는 세 반에서 동일한 읽기 전용 접점으로 공유한다. R1의 R1_84X와 UVR1, R2/R3의 UVR1 표시 신호는 별개다. 실제 전압값·84 정정치·응답 지연은 제공되지 않아 추정하지 않았다.

## 투입·개방 시퀀스

소스의 접점식을 유지하고 각 84의 입력을 위 검출 전압에 연결한다.

```text
R2 CX_PERMIT = !G86X && (!R2_84X || (!R1_A && (!R3_A || !R3_84X)))
R3 CX_PERMIT = !G86X && (!R3_84X || (!R1_A && (!R2_A || !R2_84X)))
```

- R2_84X는 상시 true이므로 R1 투입 중에는 R2 RUN 투입을 시작할 수 없다. 89-R2가 개방돼 있어도 같은 조건이며, 차단된 명령으로 단로기를 먼저 움직이지 않는다.
- 상동 측 외부 전원이 가압되면 89-R3 개방 중에도 R3_84X가 true이므로 R1·R2 상태와 보호 조건을 확인한 뒤 R3 RUN 투입을 시작한다.
- RUN 투입은 89 투입 → 1초 확인 → 52 투입 → 3초 확인이다. RUN 개방은 52 개방 → 1초 확인 → 89 개방 → 7초 확인이다. R2/R3 명령 제한 8초/10초는 유지한다.
- 외부 공급이 있는 검출점은 52와 89를 개방해도 가압 상태를 유지한다. 상동이 모선 역가압만 받던 경우에는 RUN 52 또는 89를 개방하면 검출 전압이 사라진다.
- 소스의 CX 자기유지 분기는 최초 RUN·CX_PERMIT 조건 밖에 있다. 시작한 명령을 84 변화만으로 임의 취소하지 않으며, R2/R3에 없는 UVR 트립도 추가하지 않는다.
- TEST의 CB 투입 중 DS 개방 허용과 DS 투입 시 CB 개방 조건은 사용자 확인대로 유지한다.

## 검증

`tests/primary-voltage.test.js`는 고정 온수 전원을 반영한 128개 RUN 전원·차단기·단로기 조합을 독립적인 전압 경로 식과 대조한다. 단로기 앞·뒤 구분, 단로기 개방 중 외부 전압 검출, 역가압의 두 스위치 조건, TEST 분리, 보호 트립, 상시 공급 보존, 초기화·지연 동작 취소와 세 반의 신호 공유를 확인한다. R2/R3의 순수 접점 논리 32개 조합은 별도로 유지한다.
