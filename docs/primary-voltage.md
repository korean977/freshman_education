# R2·R3 1차측 전압과 84

사용자는 R2·R3의 84가 차단기 2차측 모선 전압이 아니라 **각 89 단로기와 52 차단기 사이의 1차측 전압**을 검출한다고 확인했다. 따라서 84를 고정 true 또는 수동 체크 접점으로 다루지 않고, 실제 교육용 전원·스위치 연결 상태로부터 자동 결정한다.

## 검출점과 동작

```text
온수 측 연계선 ─ 89-R2 ─ [R2 84 검출점] ─ 52-R2 ─ 공통 AC 모선
상동 측 연계선 ─ 89-R3 ─ [R3 84 검출점] ─ 52-R3 ─ 공통 AC 모선
```

| 상태 | 84 |
| --- | --- |
| 1차측 검출점 무가압 | 비동작(false) |
| 연계선이 가압되고 해당 89가 투입돼 1차측에 전압 도달 | 동작(true), 52 개방 중에도 가능 |
| 모선만 가압되고 해당 52가 개방돼 검출점과 분리 | 모선 가압만으로 동작하지 않음 |
| 해당 52가 RUN 투입돼 가압 모선으로부터 1차측 역가압 | 동작(true), 연계선 전원이 없어도 가능 |
| 해당 52가 TEST 투입 | 주회로 연결로 계산하지 않음. 연계선·89 측 경로로만 1차측 전압 결정 |
| 유일한 전원이 상실돼 검출점 무가압 | 즉시 비동작. 별도의 UVR 트립을 만들어내지 않음 |

`power-network.js`의 한 연결 모델을 `ac-protection.js`의 전압 검출과 `power.html`의 가압 선로 색에 공통 사용한다. 기존 정류 경로의 방향성은 유지해 DC에서 AC로 역급전하지 않는다. 한전 수전은 가압, 온수·상동 연계선 전원은 초기 무가압이며 사용자가 두 연계선의 전원을 각각 설정할 수 있다. 초기 전체 기기 개방 상태에서는 두 84 모두 비동작이다.

세 반의 R2_84X·R3_84X는 같은 계산 결과를 공유하는 읽기 전용 접점이다. R1의 R1_84X 및 R1 UVR1, R2/R3의 UVR1 표시 신호는 이 두 84와 별개이며 임의로 결합하지 않는다. 실제 전압값·동작 정정치·84 응답 지연은 제공되지 않아 추정하지 않았다.

## 투입·개방 시퀀스에 반영

기존 소스의 접점식을 유지하고 그 식에 들어가는 84의 원인을 1차측 전압으로 바꾼다.

```text
R2 CX_PERMIT = !G86X && (!R2_84X || (!R1_A && (!R3_A || !R3_84X)))
R3 CX_PERMIT = !G86X && (!R3_84X || (!R1_A && (!R2_A || !R2_84X)))
```

- 무가압 1차측의 84 b접점 경로가 초기 투입 명령을 허가한다. 1차측이 가압되면 R1·반대편 차단기와 84 조건을 함께 확인한다.
- RUN은 89 투입 → 1초 확인 → 52 투입 → 3초 확인이다. 개방은 52 개방 → 1초 확인 → 89 개방 → 7초 확인이다. 명령 제한 8초/10초는 유지한다.
- 소스의 CX 자기유지 분기는 최초 RUN·CX_PERMIT 조건 밖에 있다. 따라서 89가 투입되거나 52가 투입돼 84가 바뀌어도 시작된 CX를 임의로 취소하지 않는다. 이는 원본 소스의 자기유지이며, 매 단계마다 별도 전압 허가를 새로 추가한 것이 아니다.
- 52 개방 후에도 연계선·89 측에서 전압이 공급되면 84는 계속 동작한다. 반대로 모선 역가압만 받던 1차측은 52 개방 시 무가압이 되어 89 개방 전에 84가 해제된다.
- 보호 트립이나 전원 상실·복귀 시에도 전압을 다시 계산한다. 전압이 없어졌다는 이유만으로 R2/R3에 없는 UVR 트립을 추가하지 않는다.
- TEST는 사용자 확인에 따라 CB 투입 중 DS 개방을 허용하고, DS 투입은 CB 개방 조건을 유지한다.

## 검증

`tests/primary-voltage.test.js`는 256개 RUN 전원·차단기·단로기 조합을 독립적인 세 전원 경로 식과 대조한다. 모선/1차측 구분, DS에 의한 전압 검출, 역가압, TEST 분리, 유일 전원 상실/복귀, 보호 트립, 자기유지, 초기화·지연 동작 취소와 세 반의 신호 공유를 확인한다. R2/R3 소스의 32개 순수 접점 논리 조합도 별도로 유지한다.
